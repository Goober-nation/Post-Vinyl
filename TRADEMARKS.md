# Project name & branding

The Post-Vinyl **source code** is licensed under Apache License 2.0 (see [`LICENSE`](LICENSE)) — you
are free to use, modify, and redistribute it, including as a fork, for any purpose, including
commercial, as long as you comply with that license.

That license, like most open-source licenses, **does not grant any trademark rights** (Apache 2.0
§6 says so explicitly). So separately from the code:

- The name **"Post-Vinyl"**, and any associated logo, refer to this project as maintained here.
- **Forks are welcome** — feel free to copy, modify, and redistribute the code under Apache 2.0.
- **Please don't publish a fork, a package, or a separate project under the name "Post-Vinyl"** (or a
  confusingly similar name) as if it were this project or an official version of it. Pick your own
  name for a redistributed/modified version — a quick note like "based on Post-Vinyl" or "fork of
  Post-Vinyl" pointing back here is exactly the right way to give credit instead.
- This is an informal policy, not a registered trademark — it exists so people searching for this
  project land on the real one, not so anyone can be stopped from writing similar software.
